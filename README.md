# fashion-retail-data-analysis-
MSc Business Analytics dissertation analysing customer behaviour, fashion spending and personalisation in UK fashion retail using Python and statistical modelling.
# About the Project
This project is part of my MSc Business Analytics dissertation and investigates customer behaviour and personalisation in the UK fashion retail sector.
The study focuses on understanding the factors associated with customers' fashion spending behaviour and how customer insights can support more effective personalised marketing strategies.
The project uses Python-based data analysis and statistical modelling to transform customer survey responses into meaningful business insights.

# Research Aim
The main aim of this research is to understand how demographic and behavioural characteristics influence customer purchasing and fashion spending behaviour, and how these insights can be used to support personalisation in fashion retail. The project aims to connect quantitative customer data with practical recommendations for fashion retailers.
# Technologies Used
The analysis was conducted using Python and Jupyter Notebook.
Main libraries include:
Pandas — data manipulation and cleaning
NumPy — numerical operations
Plotly — interactive data visualisation
SciPy — statistical analysis
Statsmodels — regression and statistical modelling
Jupyter Notebook — analysis development and documentation
# Expected Business Value
The analysis is intended to help fashion retailers better understand their customers and identify factors associated with purchasing and spending behaviour.
The findings can support:
More targeted marketing
Customer personalisation
Better promotional strategies
Customer segmentation insights
Improved understanding of spending behaviour
More informed customer engagement strategies
